# Email Cleaner

Streamlit-приложение для загрузки таблиц клиентов, очистки email и формирования выгрузок для разных категорий клиентов.

## Вкладки

- **Оптовые клиенты** — полный сценарий обработки с распределением по 6 фиксированным группам и формированием ZIP-архива с XLSX.
- **Корпоративные клиенты** — аналогичная очистка без группировки, выгрузка одного XLSX-файла, в названии указано количество email.
- **Розничные клиенты (база)** — очистка без группировки, оставляются только строки с пустым менеджером, выгрузка XLSX с дополнительными колонками и количеством email в названии.
- **Розничные клиенты (сайт)** — принимает XLS/XLSX, выгружает один XLSX с колонками `Фамилия` и `E-Mail` после фильтра по `Ответственный = "Интернет розница"`.

## Логика обработки (кратко)

1. **Загрузка**
   - HTML-файлы декодируются в кодировке `cp1251` с `errors="replace"`.
   - Таблицы HTML извлекаются через `pandas.read_html` с `header=1`, чтобы заголовки брались из второй строки.
   - Для вкладки «Розничные клиенты (сайт)» используются Excel-файлы (`read_excel`).
   - Названия колонок приводятся к строкам и обрезаются по краям.

2. **Нормализация колонок и поиск обязательных полей**
   - Заголовки колонок приводятся к нижнему регистру, лишние пробелы удаляются.
   - Ищутся колонки с ключевыми словами (например `клиент`, `email`, `менеджер`, `ответственный`).
   - Если в первой строке заголовков не найдены нужные поля, выполняется поиск строки-заголовка ниже и её подъём.

3. **Фильтрация данных**
   - Удаляются строки, где в колонке email нет символа `@`.
   - Удаляются строки со значениями менеджеров из списка исключений.
   - Из всех вкладок дополнительно исключаются email, которые найдены во внешних suppression-файлах рядом с `app.py`.
   - Во вкладке «Розничные клиенты (база)» дополнительно исключаются строки по ключевым словам в колонке «Клиент» и остаются только строки с пустым менеджером.
   - Во вкладке «Розничные клиенты (сайт)» остаются строки только с `Ответственный = "Интернет розница"`.

4. **Разделение и очистка email**
   - Если в ячейке несколько email, они разбиваются на отдельные строки.
   - Email очищаются (удаление пробелов, кириллицы, лишних символов) и приводятся к нижнему регистру.
   - Невалидные email исключаются.

5. **Дедупликация**
   - Повторы email удаляются, сохраняется первое вхождение.

6. **Распределение по группам (только для «Оптовые клиенты»)**
   - Пользователь выбирает менеджеров для каждой из 6 групп.
   - Один менеджер может быть выбран только в одной группе.
   - Ниже списка отображается строка с менеджерами, не выбранными ни в одной группе.

7. **Формирование выгрузки**
   - Оптовые клиенты: ZIP с XLSX по группам, в названии каждого файла указано количество email.
   - Корпоративные клиенты: один XLSX, в названии файла указано количество email.
   - Розничные клиенты (база): один XLSX с колонками `Клиент`, `Email`, `Место последней покупки`, `День рождения` и опционально `Телефон`, в названии файла указано количество email.
   - Розничные клиенты (сайт): один XLSX с колонками `Фамилия` и `E-Mail`.

## Внешние suppression-файлы (исключение email)

Если рядом с `app.py` находятся следующие файлы, email из их таблиц исключаются из всех выгрузок:

- `Ne otkravali 300 dney roznica.xlsx`
- `Status_problemnie_otdel prodaj.xlsx`
- `unsubscribed.xlsx`

Приложение автоматически пытается найти в них колонку email (`E-mail`/`Email`) и удаляет совпадающие адреса после этапа дедупликации.

## Запуск

```bash
streamlit run app.py
```
