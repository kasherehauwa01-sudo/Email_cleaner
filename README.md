# Email Cleaner

Streamlit-приложение для загрузки HTML-файла с таблицей клиентов и email, очистки данных и формирования ZIP-архива с XLSX-файлами по фиксированным группам менеджеров.

## Логика обработки (кратко)

1. **Загрузка HTML**
   - Файл декодируется в кодировке `cp1251` с `errors="replace"`.
   - Таблицы извлекаются через `pandas.read_html` с `header=1`, чтобы заголовки брались из второй строки.
   - Названия колонок приводятся к строкам и обрезаются по краям.

2. **Нормализация колонок и поиск обязательных полей**
   - Заголовки колонок приводятся к нижнему регистру, лишние пробелы удаляются.
   - Ищутся колонки с ключевыми словами: `клиент`, `email/e-mail/e mail`, `менеджер`.
   - Если в первой строке заголовков не найдены нужные поля, выполняется поиск строки-заголовка ниже и её подъём.

3. **Фильтрация данных**
   - Удаляются строки, где в колонке email нет символа `@`.
   - Удаляются строки с пустым менеджером и со значениями менеджеров из списка исключений.

4. **Разделение и очистка email**
   - Если в ячейке несколько email, они разбиваются на отдельные строки.
   - Email очищаются (удаление пробелов, кириллицы, лишних символов) и приводятся к нижнему регистру.
   - Невалидные email исключаются.

5. **Дедупликация**
   - Повторы email удаляются, сохраняется первое вхождение.

6. **Распределение по группам**
   - Пользователь выбирает менеджеров для каждой из 6 групп.
   - Один менеджер может быть выбран только в одной группе.
   - Ниже списка отображается строка с менеджерами, не выбранными ни в одной группе.

7. **Формирование архива**
   - Для каждой группы формируется XLSX с колонками `Клиент` и `Email`.
   - Все файлы упаковываются в один ZIP и доступны для скачивания.

## Запуск

```bash
streamlit run app.py
```
